01 / Production case study

OCR and an offline model identify, grade and price surplus hardware.

Surplus Station

Problem
Staff at ASU Surplus were retyping laptop specs by hand.
What I built
OCR reads hardware labels, and a self-hosted Qwen 14B model running offline across four Mac minis identifies, grades, and prices items. Command-line tools in Bash and PowerShell pull a laptop’s specs from a USB stick in seconds on macOS and Windows.
  • ~80%faster per item, in daily production use
  • ~10 minfor a 100+ unit pallet of listings, down from 1 to 2 hours

02 / Live demo

AI reads the invoice. Then it has to prove it.

Invoice Guard

Problem
AI extraction from documents can’t be trusted without checks.
What I built
AI extracts invoice fields, proves every value against the original page, checks the math, and sends only doubtful invoices to a person, whose corrections become test cases.
  • 6 of 6bad invoices caught
  • 15 of 16good ones auto-approved
  • $0.0005per invoice, roughly. A model costing 20 times more changed no decisions.
  • 113tests
  • Python
  • Claude API
  • LLM evaluation
